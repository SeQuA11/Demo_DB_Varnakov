# Demo_DB_Varnakov

Проектирование информационной системы «Гостиница» по тексту брифинга и документам заказчика
(Номерной фонд, Отчёт по состоянию номерного фонда, Постояльцы). Диаграммы выполнены в draw.io.

| Папка | Содержимое |
|---|---|
| `01_UseCase` | Диаграмма вариантов использования: гость, администратор, руководитель |
| `02_WireFrame` | Макеты 5 экранов: авторизация, номера и заявки, бронирование и заезд, график уборки, руководитель |
| `03_ERD` | ER-диаграмма БД в 3НФ: 13 таблиц, первичные и внешние ключи, связи (та же схема, что в Demo_SQL_Varnakov) |
| `04_DataDictionary` | Словарь данных: поля с типами PostgreSQL и справочные значения |
