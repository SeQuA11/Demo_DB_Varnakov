# Demo_DB_Varnakov

Модуль 2 — проектирование информационной системы «Гостиница» по тексту брифинга и документам заказчика
(Номерной фонд, Отчёт по состоянию номерного фонда, Постояльцы). Диаграммы выполнены в draw.io.

| Папка | Содержимое |
|---|---|
| `01_UseCase` | Диаграмма вариантов использования: гость, администратор, руководитель, таймер, PMS |
| `02_WireFrame` | Макеты 9 экранов: авторизация, смена пароля, номерной фонд, заявки, бронирование и заезд, график уборки, показатели руководителя, сотрудники, мобильное бронирование для гостя |
| `03_ERD` | ER-диаграмма БД в 3НФ: 19 таблиц, первичные и внешние ключи, связи |
| `04_DataDictionary` | Словарь данных: таблицы, поля с типами PostgreSQL, связи, справочные значения, замечания по исходным данным |

Файлы `.drawio` открываются в приложении draw.io или на https://app.diagrams.net
(Файл → Открыть). Экспорт в PDF: Файл → Экспорт как → PDF.
